Node 就是一個函式：收 dict、回傳 dict。重點是它只回傳自己負責的那一格，LangGraph 幫你寫回訂單紙 [4]。封膜的店員只蓋「已封膜」的章，不會去改甜度。常見錯誤：直接改 state 再整張交回去，等於每一格都被你重寫一次，別站寫好的東西可能被蓋掉；遇到「要往下接著寫」的格子（例如附錄的對話紀錄 messages），可能產生非預期合併；行為取決於 reducer 與訊息 ID。正確寫法是只 return 自己改的那一格，讓 LangGraph 幫你合併。check_syntax 的「語法檢查」只看文法，不執行程式。

核心練習完成後，再看訊息更新方式：如果訂單紙上有一格是「對話紀錄」呢？（1-B 的 agent 已用過這一格）

常見錯誤：自訂 State 沒寫合併規則
class BadState(TypedDict):    messages: list   # ← 預設行為是「覆蓋」 def bad_chatbot(state: BadState) -> dict:    response = model.invoke(state["messages"])    return {"messages": [response]}   # 覆蓋整個 list r1 = bad_graph.invoke({    "messages": [{"role": "user", "content": "我叫小明"}]})print(len(r1["messages"]))
1   ← 怪！user 訊息「我叫小明」消失了
修法：告訴它這一格要合併
class MessagesState(TypedDict):    messages: Annotated[list, add_messages]
  • 怎麼讀這行：messages 是個 list，但 LangGraph 處理時不要覆蓋，用 add_messages 合併（新 ID 新增，相同 ID 更新）
  • 口訣：Annotated 第一格是型別，後面是額外資訊；LangGraph 用它指定合併規則
  • 還記得「有歷史 vs 沒歷史」嗎？對話那一格被蓋掉，模型就忘了你是誰
訂單紙上「對話」那一格如果每次整格擦掉重寫，前面講的話就不見了；add_messages 是告訴它「這一格要往下接著寫」。

Colab1-B 第 7 段：課後選做：組出核心迴圈

附錄選做：模型與工具的核心迴圈

from langgraph.graph import START, MessagesState, StateGraphfrom langgraph.prebuilt import ToolNode, tools_condition tools = [run_code, check_indent, read_spec]model_with_tools = model.bind_tools(tools) def ask_model(state: MessagesState) -> dict:    return {"messages": [model_with_tools.invoke(state["messages"])]} builder = StateGraph(MessagesState)builder.add_node("ask_model", ask_model)builder.add_node("tools", ToolNode(tools))builder.add_edge(START, "ask_model")# tools_condition: 上一則訊息有 tool_calls 就走 tools，否則走 ENDbuilder.add_conditional_edges("ask_model", tools_condition)builder.add_edge("tools", "ask_model")  # tools 跑完繞回 ask_model agent = builder.compile()
元件做什麼
@tool函式 → 模型看得到的工具
bind_tools工具說明書附在每次呼叫上
ask_model問模型，回文字或 tool_calls
ToolNode讀 tool_calls、執行、包結果
tools_condition內建路由：有 tool_calls → tools，沒有 → END
add_edge(tools→ask_model)工具跑完回去問模型，形成循環

還是 1-A 的三個零件：一個問模型的節點、一個跑工具的節點、一條「有沒有要用工具」的 if，繞成一個圈。

create_agent(model, tools) 的核心互動可用這個圖示意；這不是完整實作：LangGraph 把「拿 tool_calls → 自己呼叫 → 包結果回去」這串重複的事自動化了。
