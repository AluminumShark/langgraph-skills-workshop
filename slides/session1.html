Tool calling：模型只會「說」它想用哪個工具

模型從頭到尾只是「說」它想用什麼工具，真正做事的是你的程式。這叫 tool calling 或 function calling [1]。

三格漫畫：1. 你的 Python 告訴模型「你有一個工具叫 run_code，可以執行程式」。2. 模型回一段文字（JSON）：{"tool": "run_code", "args": {"code": "print(1+1)"}}。3. 你的 Python 看到這段，真的去執行，把結果 2 貼回去給模型。模型從頭到尾只是「說」它想用什麼工具，真正做事的是你的程式。這叫 tool calling 或 function calling [1]。

Agent = Model + Harness

  • 模型是馬，跑得快但不一定往你要的方向
  • Harness（馬具）是韁繩和馬鞍：今天的流程圖、檢查節點、recursion limit 都是 [10]
  • 2026 年業界的共識：決定 AI 好不好用的常常不是模型，是外面這一層 [10][11]
今天三件事
  1. 1
    Agent ＝ 模型 ＋ 工具 ＋ 迴圈模型只會「說」要用哪個工具，做事的是你的程式
  2. 2
    流程鎖住不能錯的事，agent 放手處理需要判斷的事兩者可以套在一起，就是雙拼

    工具有兩種來源自己寫的函式，或 MCP 插座接進來的；都會進桌子
