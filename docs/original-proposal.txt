1. 工作坊名稱
中文名稱：
從 LangGraph 到 Skills: 結構化與非結構化 Agent 的雙拼指南
英文名稱（選填）：
Agents in 2026: Mastering LangGraph & SKILL.md
一句話介紹：
帶領學生看透 2026 年 AI Agent 兩大陣營，從構建具備絕對確定性的 LangGraph 工作流，到掌握依賴 Markdown 驅動的 Agent Skills，最終打造自己的雙核 AI 助手。

2. 為什麼值得開這個工作坊？
社群現在把 Agent Skills 捧上天，好像只要在 SKILL.md 裡寫幾句 Markdown，AI 就能自動幫你搞定一切工作。但現實是，超過三成的開源 Skills 存在 Prompt Injection 的風險，而且過度自由的 Agent 經常會「熱心過頭」導致流程失控。
這門課之所以有價值，是因為它不只教最新的酷玩具。我們會直接戳破 Skills 的神話，告訴學生為什麼許多企業級應用（包括大型科技公司內部）依然堅持使用 LangGraph 這類具備圖形結構與狀態管理的框架。學生將學會如何結合兩者的優勢：用 LangGraph 畫出不可逾越的業務邏輯紅線，並在特定節點放手讓 Agent Skills 發揮其強大的非結構化處理能力。完成後，學生不僅能將這套架構應用於個人的自動化專案，更能銜接業界真實的開發思維。
3. 核心學習成果
完成工作坊後，學生應該能夠：
設計並部署一個具備狀態管理（State Management）與條件路由的 LangGraph 流程。
撰寫符合 agentskills.io 業界標準的 SKILL.md，並理解其漸進式揭露（Progressive Disclosure）的載入機制。
評估並決策在特定任務中，何時應採用框架限制 AI，何時該釋放 AI 的自治能力。
4. 最終成果
學生在工作坊結束時，預計完成：
主要成果：一個能處理特定領域任務（例如：自動化審查程式碼並發布報告，或分析資料夾結構並整理）的「雙核 Agent」。主題還沒想好，預計是會準備一個範例內容給大家使用，也歡迎有買claude code的人自己vibe coding出屬於自己的工作流
成果形式：GitHub Repository（包含 graph.py 結構與 .claude/skills/ 目錄）。
最低完成標準：Agent 能夠成功在 LangGraph 的受控節點中，正確觸發並執行至少一個自定義的 Markdown Agent Skill，且狀態未發生丟失。

7. 課程安排
第 1 堂：LangGraph - 讓野馬戴上韁繩
目標：
目標：打破「AI 會自己想辦法」的迷思，建立對確定性工作流的認識。 
主要內容：
介紹 2026 年企業端為何仍依賴 Graph 架構
實作 State 定義、Nodes 建立與 Conditional Edges 的配置
探討如果沒有框架，AI 會怎麼把事情搞砸。
課堂實作：
建立一個基礎的審查 Agent 框架，規定它必須先完成 A 才能做 B。
課後進度：
在自己的電腦裡面可以跑一個確定性的工作流 由淺入深
第 2 堂：Agent Skills - Markdown 魔法與幻覺的代價
目標：
理解 Agent Skills 的本質與開放標準（agentskills.io），並學會打包個人的 Domain Knowledge
主要內容：
剖析 SKILL.md 的三階段漸進式揭露系統（Metadata -> Instructions -> Resources）。
論為何這種看似聰明的機制，在缺乏審查時容易產生嚴重資安風險與幻覺。
下載一個SKILL.md，自己寫出一個SKILL.md（可以vibe coding）
課堂實作：
寫一個實用的自定義 Skill（例如資料整理或文案風格化），並在本地端測試觸發條件。
課後進度： 可以自行嘗試用更多的api key實作


第 3 堂（可來可不來）：雙核 Agent 實作 - 在框架中自由跳舞
目標：
整合前兩堂的技術，完成最終專案。
主要內容與實作：
將第 2 堂寫好的 Skills 作為 Tools 嵌入到第 1 堂的 LangGraph 節點中。下半場進行分組 Demo 與同儕 Code Review。講師會針對架構設計提供諮詢與批判性建議。
8. 教學方式
預計採用的教學形式：講授與觀念說明、Live Coding、分組實作、專案諮詢。
預計講授與實作比例：講授 40% ／ 實作 60%。
協助方式：隨時進行 Code Review，並引導學生觀察 Agent 發生錯誤時的 Trace log，而不是直接給標準答案。
